my github

My interest in computers has resulted in a few concentrated outputs of code over the last year or two. Part of it has been just configuring my apps that I use, being the kitty terminal, neovim, and my linux install (arch btw), but the original goal was to use my graphics card to do fun or interesting simulations, like Shadow the Hedgehog staring at his own shadow, or terrain generation.

To do this I went through all of the tutorials on learnopengl and ended up making an elementary PBR rendering engine, whilst implementing other fun things like instanced object, bloom, antialiasing, and so on...

My one and only contribution to an open source project is the Popping and Locking theme for the kitty terminal, so if you end up trying out the kitty terminal be sure to check it out :)
